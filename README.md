# 委圖小幫手

作者：懶人阿暝

> ⚠️ **本專案禁止任何商業／營利用途。** 個人免費使用、學習、非營利分享都歡迎，詳見下方〈授權與使用規範〉。

可愛風格的委圖整理工具，幫你把角色卡、參考圖、委託單和構圖示意圖整理好，再翻成繪師看得懂的語言。只要一個 HTML 檔就能跑，不需要後端。

## 功能

- **角色卡**：可以填角色名稱、年齡、性別、身高、其他基本資料、外貌、服裝・配件、個性・表情、必畫重點、NG／請避免和其他。每張卡可以放多張參考圖（會自動壓縮，可以設定封面），也有色票，預設先放好髮色、瞳色兩格，可以自由增減、加上名稱。
- **委託單**：按「＋ 委新圖」填一張委託單。構圖範圍可以選**大頭貼／胸口／半身／全身**，再把要畫的角色卡加進來，人數會自動計算。其他欄位有背景（透明／簡單／完整）、用途（個人／商業）、尺寸、預算、期限、繪師、構圖情境、表情動作、備註，還有只有自己看得到的進度（草稿／詢價中／進行中／已完成）。
- **多語翻譯**：預設有日本語、한국어、English 三個語言分頁，也可以在「設定」新增其他語言，例如简体中文、Español、ไทย。翻譯有三種方式：
  1. **翻譯檔（不需要任何金鑰）**：按「翻譯 → 匯出翻譯檔」，複製後貼給 ChatGPT、Gemini 等任何 AI。檔案開頭已經寫好給 AI 的說明，AI 會照 `[[...]]` 標記的格式翻好。再按「匯入」貼回來，就會自動填回每張角色卡和委託單。自訂語言會連欄位名稱一起翻。
  2. **自填 Gemini API 金鑰（選用）**：在「設定」貼上自己的 Google Gemini 金鑰，就能一鍵自動翻譯。**請只使用免費、沒有綁信用卡的金鑰**，詳見下方〈注意〉。
  3. 在 Claude 裡打開時，會直接用 Claude 翻譯。
- **匯出**：角色卡和委託單都能匯出成**文字檔（.txt）**或**圖卡（.png）**，也可以選「全部語言」一次匯出多語文字。委託單的圖卡會把委託內容、示意圖和每個角色的設定排在一起。構圖範圍、背景、用途這些選項會自動換成對應語言的說法，例如「半身」在日文會寫成「腰上（半身）」。
- **示意圖**：
  - 可以放小人，有 10 種預設動作，拖曳圓點可以調手腳、頭和身體角度。每個小人可以設名字、顏色和身高（40–220 cm），旁邊有身高刻度方便比身高，也能從角色卡直接帶入名字、身高和代表色。
  - 有 8 種**雙人互動**：牽手、擊掌、比愛心、擁抱、搭肩、遞東西、面對面、背靠背。手的位置會依兩人身高自動對齊。
  - **取景**：一鍵切換大頭貼／胸口／半身／全身；也可以用 −／＋ 等比例縮放，或用「移動畫面」拖曳整個畫面。
  - **圖層**：可以調整上下順序、隱藏或顯示，也能開好幾層筆跡；橡皮擦只會擦到目前選的那一層。
  - **畫布尺寸**：預設有 3:4、1:1、IG 4:5、手機桌布 9:16、16:9、A4 直式和橫式，也可以自訂。
  - 有畫筆、橡皮擦、復原，可以匯出 PNG。從委託單按「用這些角色畫示意圖」，會自動建好一張示意圖。
- **主題色**：右上角可以切換草莓牛奶、薄荷汽水、薰衣草、奶茶、晴天五種顏色，深色模式也會跟著換，選過的顏色會記住。
- **加入主畫面**：附有 App 圖示。在 iPhone 用 Safari「加入主畫面」，會像 App 一樣全螢幕開啟。
- **備份**：所有資料可以下載成一個 `.json` 備份檔，在別台裝置或別的瀏覽器匯入。

所有資料和圖片都在瀏覽器裡處理，不會上傳到任何伺服器。唯一的例外是你自己填了 Gemini 金鑰並按下「自動翻譯」時，要翻譯的文字會送到 Google。

## 部署到 GitHub Pages

1. 把 `index.html`、這份 `README.md`、`LICENSE`，以及圖示檔 `apple-touch-icon.png`、`favicon-32.png`、`icon-192.png`、`icon-512.png`、`manifest.webmanifest` 全部放進 repo 根目錄，push 上去。
2. 進 repo 的 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
3. 等一兩分鐘，網址會是 `https://<你的帳號>.github.io/<repo 名稱>/`。

## 注意

- 資料是存在**每個使用者自己的瀏覽器**裡（IndexedDB）。換手機、換瀏覽器、用無痕模式，或清除網站資料之後，就會看不到，請常用「設定 → 下載備份檔」備份。
- iPhone「加入主畫面」後打開的版本，和 Safari 裡的版本**資料不互通**。要搬資料，請在 Safari 版下載備份檔，再到主畫面版匯入。
- **關於 API 金鑰**：
  - 請只使用 **Google AI Studio 的免費金鑰，而且不要設定帳單（不要綁信用卡）**。這樣就算金鑰外流，最多只是當天的免費額度被用完，不會被扣錢。
  - 金鑰只存在你自己的瀏覽器（localStorage），不會寫進程式碼，也不會放進備份檔。**千萬不要把金鑰寫進 `index.html` 再上傳到 GitHub。**
  - 免費方案的內容可能會被 Google 用來改進產品，不想公開的設定請改用翻譯檔。
  - 免費額度會隨 Google 政策變動，建議使用額度最多的 Flash-Lite 模型。實際額度請到 Google AI Studio 查看。
- 翻譯檔是用角色卡和委託單的內部編號對位置，所以請在**同一個網站、同一個瀏覽器**匯出和匯入。
- 字型（Huninn、M PLUS Rounded 1c）由 Google Fonts 載入，第一次開啟需要網路連線；沒有網路時會改用系統字型。
