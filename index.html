AI 自動翻譯（選用）

⚠ 請只使用「免費、沒有綁信用卡」的 API 金鑰。
這樣就算金鑰外流，最多只是當天額度被用完，不會被扣錢。不填也沒關係，一樣可以用上面的「翻譯檔」貼給任何 AI 翻。

目前支援 Google Gemini：到 Google AI Studio（aistudio.google.com）登入後按「Get API key」建立金鑰，不要設定帳單。金鑰只存在這支手機的瀏覽器裡，不會放進備份檔，也不會傳給 Google 以外的地方。免費方案的內容可能會被 Google 用來改進產品，不想公開的設定請改用翻譯檔。在 Claude 裡打開時會直接用 Claude 翻譯，這個設定是給自己架的網站（例如 GitHub Pages）用的。

建議用 Flash-Lite：免費額度最多，翻譯也夠用。

備份與資料

角色卡、照片和示意圖都只存在這支手機的這個瀏覽器／App裡，不會上傳到任何地方。換手機、清除瀏覽器資料、或改用別的瀏覽器開啟時就看不到，建議每次改完都下載一份備份檔。
